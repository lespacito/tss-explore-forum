# Files d'exécution

Une file contient un lot homogène, avec un skill, un produit et une langue.

```text
# Lot : <nom> : produit : Parlons Violence : langue : fr
# Skill : <comparison-page | statistics-article | foundational-article | free-tool | internal-linking | directory-submission>
# Règle : un item passe de [ ] à [x] quand il est terminé, avec le chemin du livrable.

- [ ] item-001 | <titre ou slug> | requête : <…> | cluster : <…> | livrable :
```

Un seul item est produit par cycle du jour. Toute affirmation médicale, juridique, statistique ou relative à la sécurité doit être vérifiée ou retirée avant publication.
