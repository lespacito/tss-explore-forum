# Raccourcis Clavier - Éditeur de Texte

## Raccourcis de Formatage

### Formatage de Texte
- **Gras** : `Ctrl+B` (Windows/Linux) ou `Cmd+B` (Mac)
- **Italique** : `Ctrl+I` (Windows/Linux) ou `Cmd+I` (Mac)

### Titres et Structure
- **Titre niveau 2** : `Ctrl+Alt+2` (Windows/Linux) ou `Cmd+Alt+2` (Mac)

### Citations et Listes
- **Citation** : `Ctrl+Shift+B` (Windows/Linux) ou `Cmd+Shift+B` (Mac)
- **Liste à puces** : Cliquez sur le bouton dans la barre d'outils
- **Liste numérotée** : Cliquez sur le bouton dans la barre d'outils

## Raccourcis Généraux

### Navigation et Édition
- **Annuler** : `Ctrl+Z` (Windows/Linux) ou `Cmd+Z` (Mac)
- **Refaire** : `Ctrl+Shift+Z` ou `Ctrl+Y` (Windows/Linux) ou `Cmd+Shift+Z` (Mac)
- **Saut de ligne** : `Shift+Enter` (insérer un retour à la ligne sans créer un nouveau paragraphe)
- **Nouveau paragraphe** : `Enter`

### Navigation au Clavier
- **Tab** : Naviguer vers l'élément suivant (barre d'outils ou contenu)
- **Shift+Tab** : Naviguer vers l'élément précédent
- **Flèches** : Déplacer le curseur dans le texte

## Accessibilité

### Lecteurs d'Écran
- La barre d'outils annonce l'état actif/inactif de chaque bouton
- Chaque bouton possède une étiquette descriptive
- L'éditeur annonce "Zone de texte avec formatage, multiligne"

### Indications Visuelles
- Les boutons actifs sont mis en surbrillance
- Le focus clavier est visible avec un contour distinct
- Contraste minimum de 4.5:1 (WCAG 2.1 AA)

## Conseils d'Utilisation

### Pour une Navigation Rapide
1. Utilisez `Tab` pour atteindre rapidement la barre d'outils
2. Utilisez les flèches pour naviguer entre les boutons
3. Appuyez sur `Entrée` ou `Espace` pour activer un bouton

### Pour Éviter la Souris
Tous les outils de formatage peuvent être utilisés via les raccourcis clavier listés ci-dessus, sans nécessiter de cliquer sur les boutons.
