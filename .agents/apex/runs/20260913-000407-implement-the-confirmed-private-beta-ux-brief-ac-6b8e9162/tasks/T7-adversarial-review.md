# T7 — Adversarial review

Objective: independent review of UX intent, accessibility, security/recovery, migration, moderation and test coverage.

Depends on: T6 evidence.

Owner: delegated reviewer, read-only. Allowed write: review report artifact only. No source edits or external actions.

Evidence contract: ranked findings with file/line references, exploit or failure scenario and recommended minimal correction. Coordinator reproduces every material claim. Stop when report is complete.
