# Hermes workspace — Parlons Violence

Ce workspace est utilisé par Hermes Agent pour travailler sur **Parlons Violence**.

## Flux de travail

- Toute modification doit passer par une **branche dédiée** (par exemple `hermes/<tâche>` ou `feature/<tâche>`).
- Aucune modification directe sur `dev`, `master` ou `prod`.
- Les changements sont revus (review + checks) avant intégration dans `dev`.

## Ce que ce fichier documente

- Le contexte d'utilisation du workspace par Hermes Agent.
- La règle générale : branche dédiée + revue avant merge dans `dev`.

Ce fichier est une documentation d'usage du workspace, pas un document de produit.
